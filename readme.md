## How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/abhishekthakur797/30-days-30-javascript-project
   ```
2. Open `index.html` in your browser (or use the VS Code Live Server extension).
3. If you change any Tailwind classes, rebuild the CSS:
   ```bash
   npm install
   npx tailwindcss -i ./src/input.css -o ./src/output.css --watch
   ```
